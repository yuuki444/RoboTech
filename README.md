# RoboTech Hub

## О проекте
**RoboTech Hub** - клиент-серверное веб-приложение для любителей робототехники, Arduino и ESP32. Проект решает проблему поиска качественных уроков, покупки необходимых радиодеталей и проверки знаний по микроконтроллерам в едином интерактивном пространстве.

## Стек технологий
* **Backend:** Go (Golang), Gorilla Mux, Gorilla WebSocket, JWT, bcrypt.
* **Базы данных:** 
  * *PostgreSQL* - структурированные данные (пользователи, каталог товаров, корзина, видео).
  * *MongoDB* - неструктурированные данные (история чата в реальном времени, комментарии).
* **Frontend:** HTML5, CSS3, JavaScript (SPA интерфейс).

## Структура проекта
- `handlers/` - REST API контроллеры и WebSocket обработчики
- `models/` - структуры данных для PostgreSQL и MongoDB
- `database/` - подключение и инициализация баз данных
- `middleware/` - JWT-авторизация
- `static/` - веб-интерфейс (Frontend)

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте файл `.env` на основе `.env.example`.
3. Установите зависимости и запустите проект
   ```bash
   go mod tidy
   go run main.go
